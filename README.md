# FOMI project website

**FOMI: A Force-Feedback Manipulation Interface for Teaching Contact-Rich Manipulation**

This `github-page` branch contains the project website. The `main` branch is reserved for the project README and research code.

## GitHub Pages

To publish this branch, open **Settings → Pages**, select **Deploy from a branch**, then choose **github-page** and **/ (root)**.

The project website address will be https://robbyant-research.github.io/FOMI/ once Pages is enabled and deployment succeeds.

## Local preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/.

The website uses static HTML, CSS, and JavaScript. Videos are compressed, silent MP4 files. Paper, Code, and CAD buttons remain placeholders until their release links are supplied.
